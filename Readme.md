*** Quick note
You can enjoy the game with your friends on the same local network
Or test multiple instances of the game yourself on your device

Notice: Can't host two rooms in one device because game using one PORT for broadcast and host SERVER

*** HOW TO BUILD THE GAME

Use Godot version 4.6

Goto debug -> customize run instances -> enable multiple instances and now game can run more than 1 instances in a device

Add Export Template: Editor -> Manager Export Templates -> Go Online -> Download and Install -> Wait util it finishes

Export the game: Project -> Export -> Add -> Choose Windown Platform -> Export Project -> Save 

Game will be located at the folder that you chose to export
